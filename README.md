BBC News Classification Project

📌 Project Overview

The BBC News Classification project is a machine learning-based application that automatically classifies news articles into their respective categories using Natural Language Processing (NLP) and supervised machine learning algorithms.

The system analyzes the text of a news article and predicts its appropriate category.

🎯 Objectives

- Automatically classify BBC news articles.
- Understand and process text using NLP techniques.
- Compare different machine learning algorithms.
- Improve news organization and information retrieval.

⚙️ Technologies Used

- Programming Language: Python
- Machine Learning: Scikit-learn
- NLP: GloVe Word Embeddings
- Libraries: NumPy, Pandas
- Models: Naive Bayes, K-Nearest Neighbors (KNN), Decision Tree, Radius Neighbors

🧠 Methodology

1. Data Collection: Load the BBC news dataset.
2. Text Preprocessing: Clean and prepare the news text.
3. Feature Extraction: Convert text into numerical representations using GloVe embeddings.
4. Model Training: Train supervised machine learning models.
5. Classification: Predict the category of a news article.
6. Evaluation: Compare the performance of different models.
